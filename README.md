# SoundPulse 🎵
> A fully online, 100% ad-free modern music streaming web application.

SoundPulse provides unlimited music discovery and listening with **zero ads, zero audio sponsor messages, zero subscriptions, and zero tracking**.

---

## 🌟 Features

- **Decentralized Music Streaming**: Powered by Audius, streaming millions of full tracks across electronic, hip-hop, pop, rock, lo-fi, ambient, and indie artists.
- **40,000+ Live Radio Stations**: Commercial-free stations from around the globe (Lo-Fi 24/7, Radio Paradise 320k HD, SomaFM Groove Salad, Classic Vinyl HD, BBC, KEXP, and more).
- **Interactive Audio Visualizer**: 3 dynamic canvas visualizations reacting to audio frequencies:
  1. *Spectrum Bars*: Multi-color equalizer bars with peak drop indicators.
  2. *Laser Waveform*: Oscilloscope neon glowing wave.
  3. *Radial Aura*: Circular disco ring with floating particles.
- **10-Band Graphic Equalizer**: Precision sliders (32Hz to 16kHz) + presets (*Bass Boost*, *Treble Boost*, *Vocal*, *Electronic*, *Rock*, *Pop*, *Lo-Fi*, *Flat*).
- **Sleep Timer**: Automatically fades audio out after 15m, 30m, 45m, 60m, or at the end of the current song.
- **My Library & Custom Playlists**: Star songs into your Liked collection and track listening history saved directly in your browser.
- **Custom Audio Stream URL**: Play any direct MP3, AAC, or M3U8 web stream URL.
- **Local Audio Drag & Drop**: Drop your own MP3, WAV, or FLAC files straight into the browser.
- **Native Media Keys & Lockscreen**: Full `navigator.mediaSession` integration for keyboard play/pause/skip and Bluetooth devices.

## 🚀 How to Run

### Method 1: 1-Click Launch (Recommended)
Right-click `start-app.ps1` and select **Run with PowerShell** (or run `powershell -ExecutionPolicy Bypass -File .\start-app.ps1`).  
This launches a lightweight local server and opens SoundPulse in your default browser at `http://localhost:8080/`.

### Method 2: Direct File Open
Simply double-click `index.html` to open directly in Microsoft Edge, Google Chrome, Brave, or Firefox.

## ⌨️ Keyboard Shortcuts

| Key | Action |
| --- | --- |
| <kbd>Space</kbd> | Play / Pause |
| <kbd>→</kbd> / <kbd>←</kbd> | Seek forward / backward 5 seconds |

| <kbd>L</kbd> | Like / Favorite current track |
